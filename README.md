# 🛒 Minha Lista de Compras

Projeto simples de uma lista de compras interativa onde é possível adicionar, marcar e excluir itens.

## 🚀 Tecnologias
* HTML5
* CSS3
* JavaScript (Vanilla)

## 🛠️ Como usar
1. Digite o nome do item no campo de texto.
2. Clique em "Adicionar" ou aperte Enter.
3. Clique no item para marcar como "comprado".
4. Clique no botão "Excluir" para remover da lista.
